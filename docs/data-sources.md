# Data sources and provenance

## Allowed initial sources

- Profiles submitted directly by their owners.
- Demo records explicitly marked as demo.
- Institutional directories only after documented authorization.

## Display requirements

Every searchable record must carry a source type and freshness state. Imported or authorized records must include an internal authorization reference and a correction path.

The product must never imply that a profile is verified merely because it exists. Verification requires a documented review or trusted source process.

## Disallowed behavior

The MVP will not scrape LinkedIn, automate LinkedIn logins, bypass access controls, or copy restricted search results. It will not expose private email addresses, phone numbers, or sensitive attributes by default.
