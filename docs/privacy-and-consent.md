# Privacy and consent

The MVP is designed around data minimization and explicit consent. A profile is searchable only when its owner has selected a visibility setting and accepted the current purpose text.

The application should record:

- consent purpose version;
- consent timestamp;
- selected visibility;
- source and collection context;
- withdrawal timestamp when consent is revoked.

Profile owners must be able to edit, hide, export, and delete their profile. Deletion behavior and retention periods require a geography-specific legal review before production launch. This document is product guidance, not a claim of legal compliance.
